# Returns and Refunds Policy — NovaGadget

## Return window
Items can be returned within 30 days of delivery for a full refund, as long as they are unused and in original packaging. Opened software licenses and gift cards are final sale.

## How to start a return
Customers start a return from "My Orders" by selecting the item and choosing "Return this item." This generates a prepaid return label. Returns without a generated label cannot be processed.

## Refund timing
Refunds are issued to the original payment method within 5-7 business days after we receive and inspect the returned item. Store credit refunds, when chosen instead, are issued instantly.

## Damaged or defective items
If an item arrives damaged or defective, the customer does not need to pay for return shipping, and can choose between a replacement or a full refund. Photos of the damage speed up processing but are not strictly required.

## Refunds over $200
Any refund request over $200 must be reviewed by a human support agent before being issued. This is a compliance requirement and should never be approved automatically by the support bot.

## Exchanges
We do not process direct exchanges. Customers should return the original item for a refund and place a new order for the replacement item.
